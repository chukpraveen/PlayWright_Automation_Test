Step 1: Clone the repo
Step 2: Before cloning , download VS code
Step 3: After Vs code, create a folder and map th that folder.
Step 4: Run the comands in terminal for playwright : npm init playwright@latest
Step 5: Select Typscript
Step 6: Execute complete 3 test cases using commad : npx playwright test
Step 7: Too execute with headed : npx playwright test -- headed
Step 8: To dubug : npx playwright test -- debug
Step 9: To execute only invidual tests : npx playwright test -g "Test Case 3:Cart verify products calculations" --headed
Step 10: To see reports : npx playwright show-report
